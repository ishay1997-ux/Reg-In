## 2. חוקי ברזל ארכיטקטוניים ואינווריאנטים (Architectural Invariants)

1. **נתיב לקוח Supabase:** ייבוא אך ורק דרך `@/supabaseClient` (הנמצא ב-`src/supabaseClient.js`). הנתיב `@/lib/supabaseClient` אינו קיים ושובר בילד.
2. **חבילת Radix מאוחדת:** כל פרימיטיב של Radix מיובא אך ורק מתוך חבילת העל `radix-ui`:
   ```javascript
   import { Dialog as DialogPrimitive } from 'radix-ui'
   ```
   אין להתקין או לייבא חבילות נפרדות של `@radix-ui/react-*`.
3. **Tailwind v4 בלבד:** כל ההגדרות, הטוקנים וערכות הנושא מוגדרות ב-`src/index.css` תחת `@theme inline`. אין ליצור קובצי `tailwind.config.js` או `postcss.config.js` (הם יתעלמו בשקט).
4. **עברית ו-RTL פיזי:**
   - השימוש ב-Tailwind הוא אך ורק ב-utilities פיזיות שהופכו ל-RTL: `mr-60`, `pr-9`, `right-0`.
   - **איסור מוחלט:** אין להשתמש ב-utilities לוגיות (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`). מכיוון ש-`<html dir="rtl">` מוגדר, utility לוגית כמו `ms-60` נפתרת לימין (בדיוק היכן שיושב הסרגל) ומסתירה תוכן.
5. **רכיבי shadcn ב-RTL:**
   - רכיבי `src/components/ui/` ערוכים ידנית ל-RTL מלא. `components.json` מוגדר עם `"rtl": false` במכוון כדי למנוע דריסת RTL. אין להריץ `npx shadcn add` ללא ביקורת ידנית.
   - כל משטח Radix שנפתח ב-portal מקבל תכונת `dir="rtl"` מפורשת (`DialogContent`, `SelectContent`, `DropdownMenuContent`).
6. **שפת עיצוב קבועה:** צבע ראשי Teal `#0F766E`, רקע `#F8FAFC`, סרגל צד ימני. כפתורים משתמשים בגודל `h-auto py-2 px-4`. כפתור-אייקון = `variant="link"` + `className="h-auto p-0"`.
7. **נכסי מדיה וגופנים:** הלוגו הראשי יושב ב-`src/assets/reg-in-logo.png` (ולא ב-`public/`) כדי לאפשר הטמעה ישירה כ-Data URI (`?inline`) במנוע הפקת ה-PDF (`quotePdf.jsx`).

## 3. פנקס מלכודות שקטות ב-Frontend (Silent Traps Register)

| מלכודת שקטה | מדוע הבאג שורד קומפילציה ובדיקות | התוצאה והפתרון ההנדסי המחייב |
|---|---|---|
| **חסימת RLS שקטה בעדכון נתונים** | שאילתת `update` שנחסמת ב-RLS מחזירה `error: null` אך מעדכנת 0 שורות. ה-UI חושב שהשמירה הצליחה | יש להצמיד תמיד `.select()` לכל פעולת כתיבה/עדכון, ולוודא שהמערך המוחזר אינו ריק |
| **משטח צף שנסגר ב-`blur`** | שימוש ב-`onBlur` עם `setTimeout` לסגירת רשימה נפתחת: לחיצה מוציאה פוקוס ומפעילה טיימר שסוגר את הפאנל לפני שלחיצת המשתמש נקלטת | שימוש בניהול מצב גלוי או האזנה ל-`pointerdown` במקום `onBlur` |
| **סנכרון מצב ב-URL עם פונקציית Setter** | העברת פונקציית עדכון ל-setter שאינו תומך ב-`resolveNext()` ממירה את גוף הפונקציה למחרוזת וכותבת אותה ל-URL | עדכוני URL Search Params חייבים לעטוף את הערך ב-`resolveNext()` המטפל הן בערכים ישירים והן ב-`(prev => ...)` |
| **אובדן מצב כשל בטעינה תלת-ערכית** | כשל בשליפת נתונים שכותב `{}` או `[]` ל-state מציג מסך ריק כאילו "אין נתונים" במקום באנר שגיאה | כשל חייב לשמור `null` מפורש ב-state ולהפעיל דגל שגיאה ייעודי |
| **חוסר התאמה בשעון המקומי מול שרת** | חישובי תאריכים ב-JavaScript המשתמשים ב-`getUTCHours()` במקום שעון ישראל יוצרים הזזת תאריכים בחצות | שימוש בספריית `src/lib/dates.js` המטפלת באזור זמן ישראל |

## 4. מוסכמות קוד ובקרת איכות מסכים (5-Pass Screen Quality Pass)

לפני שמסך או דיאלוג חדש מוכרז כמוכן, יש להעביר אותו ב-5 המעברים ההנדסיים:
1. **מעבר כיווניות (Direction):** יישור תוויות ימינה, סדר תווים תקין של סימן ה-₪ והמינוס ביחס לספרות (אין ערבוב של ₪50 ו-50 ₪ באותו מסך).
2. **מעבר מלאי (Inventory):** אלמנט ללא תפקיד מובהק נמחק; אין כפתורים כפולים; טורקיז מלא שמור לפעולה הראשית של המסך.
3. **מעבר אחידות (Consistency):** אייקונים בגודל `size-4` מ-`lucide-react`, כפתור-אייקון `variant="link"`, צבעי מערכת בלבד (ללא סגול/כתום). ארכוב רשומות מבוצע באייקון ארכיון, מחיקת טיוטה באייקון פח.
4. **מעבר ניסוח (Copywriting):** תווית ממשק היא צירוף-שם ולא משפט/פועל מתורגם (למשל: "סיבות דחייה" ולא "למה הפסדנו"). ללא מטאפורות מיובאות ("צנרת", "משפך").
5. **מעבר שדה ריק (Empty Input):** כל שדה קלט ריק מחייב `placeholder` שמציג פורמט לדוגמה (תאריך `DD/MM/YYYY`, מספר טלפון, וכו').
