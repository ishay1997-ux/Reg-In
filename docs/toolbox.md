## 🤖 הבדיקה שמגנה על הקובץ הזה

`npm run check:context` (‏`scripts/check-context.mjs`) מוודא ש**הקובץ הזה תואם למציאות** ושאף סקיל
לא מפעיל סוכן מפלאגין כבוי — כשל שאחרת מתגלה רק חודש אחר-כך, בזמן ריצה, בשקט.
הוא רץ **אוטומטית בפתיחת כל סשן** (שקט כשתקין), ידנית, וכשלב חוסם ב-`npm run gate` ובסגירת מודול.
**אם שינית פלאגין כאן — הרץ אותו, או פשוט פתח סשן חדש והוא יגיד לך.**

## 🧭 מדיניות: מתי בכלל להפעיל סקיל

`module-blueprint` / `module-build` / `module-close` הם **זרימת-העבודה הרגילה** — נטענים לפי הטריגר
בלי לשאול. **כל סקיל אחר: קלוד מציע בשורה אחת ("זה נראה מקרה ל-X — להריץ?") וממתין.**
משימה קטנה לא מצדיקה סקיל; אם התשובה ברורה — פשוט לענות.

## 🔬 איך בודקים ומשפרים סקיל — מה בדיוק להגיד

**המשפטים כאן מילה-במילה, כי הניסוח הוא שקובע מה יקרה** — ניסוח קרוב-אבל-לא-מדויק מחזיר
אישור ריק במקום מדידה.

| מה אתה רוצה | מה להגיד |
|---|---|
| **למצוא בעיות בסקיל קיים** | *"תסרוק לי את `<שם>` — אילו כללים שם באמת יכולים לרוץ ומה אפשר לקצץ"* |
| **לדעת אם סקיל באמת עוזר** | *"תריץ 3 בדיקות לסקיל `<שם>` דרך `skill-creator` — כל בדיקה **פעם עם הסקיל ופעם בלי**, ותשווה"* |
| **לשפר סקיל אחרי בדיקה** | *"תיקח את מה שהצד בלי-הסקיל מצא ולא הסקיל, ותכניס פנימה. אחר כך תריץ שוב את אותן 3 — רק את הצד עם הסקיל"* |
| **ליצור סקיל חדש** | *"צור סקיל שעושה `<מה>` דרך `skill-creator` — ותריץ לו 3 בדיקות עם ובלי"* |

🔴 **המילים "פעם עם ופעם בלי" הן הקריטיות.** בלעדיהן הסשן מריץ את הסקיל שלוש פעמים ומדווח
שהוא עובד — **ואין לזה ערך, כי אין מול מה להשוות.** *(נמדד 04–05/08/2026 על `skill-scan`:
סבב 1 ניצח 2 מ-3 והפסיד באחת — **וההפסד הוא שהוליד את השיפורים האמיתיים**, כי הצד-בלי-הסקיל
השתמש בשתי שיטות שלא היו בו. סבב 2 ניצח 3 מ-3. בלי הצד השני, ההפסד היה נראה כמו הצלחה.)*

**בסבב שיפור מריצים רק את הצד עם-הסקיל** — ריצות-הבסיס לא השתנו. חוסך חצי מהעלות.

**שתי מילים ששוות להוסיף:** **"סשן טרי"** — אם הסקיל נכתב באותה שיחה, קלוד מבקר את עצמו
(נמדד: תפיסה-עצמית אפס; ראו `_shared/failure-modes.md` 🅰️) · **"קריאה בלבד"** — אם סשן אחר
עובד במקביל.

⚠️ **עלות:** סבב מלא של 3 בדיקות עם-ובלי הוא ~6 סוכנים, בערך 400K טוקנים. משפט שאומרים
כשבאמת רוצים תשובה, לא כשגרה.
