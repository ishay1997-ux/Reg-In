# תיקיית-המחיקה — קבצים שהוצעו למחיקה, ומחכים לישי

> **מה זה:** עובד שסבור שקובץ מיותר **אינו מוחק אותו — הוא מעביר אותו לכאן** ומסביר למה.
> **המחיקה עצמה היא של ישי בלבד.**
>
> **למה ככה:** מחיקת מסמך שמחזיק הכרעה **מחייבת סשנים עתידיים** — כלומר קשה-לחזור, כלומר שלו
> לפי מבחן-הסמכות. ‏**אבל "המלצה והמתנה" משאירה את הקובץ בדרך.** העברה לכאן מוציאה אותו
> מהדרך מיד, **בלי לאבד כלום.** *(הכרעת-ישי, 01/08/2026.)*

## מה חייב להיות בכל העברה לכאן

**קובץ שמועבר לכאן מגיע עם שורה בהודעה לישי:**
1. **למה הוא מיותר** — כפילות? התיישן? מעולם לא נקרא?
2. 🔴 **מה נקצר ממנו לפני ההעברה, ולאן** — עובדה שעדיין רלוונטית **חייבת בית קבוע לפני
   שהקובץ יוצא.** *"קוצרים לפני שמוחקים."*
3. **מי הפנה אליו** — ואם מישהו הפנה, **ההפניה תוקנה?**
