# REG-IN — מפת התיעוד (Index)

> קובץ זה הוא נקודת הכניסה לתיעוד. הוא **מפה ומצביע בלבד** — התוכן עצמו חי בקבצים המקושרים, כדי לא לשכפל מידע (סנכרון מקור-אמת-יחיד).

## סדר קריאה מומלץ
1. **[מדריך מאקרו](REG-IN_מדריך_מאקרו.md)** — ה-SSOT התפעולי / מדריך-העל: הקשר וסביבה, כללי עבודה (כולל כללי AI), מפת תיקיות, פרוטוקול סנכרון DB, ולוג סטטוס. **התחל כאן.**
2. **[PROJECT_MASTER](PROJECT_MASTER.md)** — האפיון המסונתז: סכמת DB, מטריצת הרשאות, ותיאור כל 17 המסכים. מקור האמת ל"מה בונים".
3. **[schema.sql](schema.sql)** — סכמת ה-DB בפועל (החוזה הטכני הקשיח).
4. **[מדריך מיקרו — מודול 1](micro_guides/REG-IN_מדריך_מיקרו_מודול_1.md)** — מתכון צעד-אחר-צעד לבניית המודול.

## היררכיית מקורות אמת (הגבוה גובר בסתירה)
`schema.sql` ← האפיון המאושר (פרקים 5–6, ראו `reference_spec/`) ← המוקאפים (רפרנס ויזואלי בלבד).
