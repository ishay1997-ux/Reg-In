**Operationalized:** the manager states **who · why · what it returns · what it costs**, waits,
and on approval may run several in parallel. **The bar is usefulness, not thoroughness-theatre
("לא בכוח" applies).** Unchanged by this: a specialist's output is a **report to verify**, never a
verdict, and anything that is a *decision* rather than a *check* — product intent, visual approval,
merges — stays Ishay's regardless of what an agent returns.
**Why it matters economically (measured 02/08):** a subagent reads in ITS own context and returns a
short report ⇒ it **saves** manager context and costs Ishay nothing to paste; a new session re-reads
everything on his quota. **The deciding test: will I need it again in an hour? No ⇒ agent (it holds a
skill). Yes ⇒ session (it holds knowledge that exists nowhere else).** *(Anchor: the four manager
consults on 01/08 had to be sessions — only they held "what made you stop the builder", which no
agent could reconstruct.)*
