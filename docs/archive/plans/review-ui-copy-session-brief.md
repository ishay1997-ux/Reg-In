### ח4 · 🔴 חוסם — `isolation:'worktree'` **אינו עובד** בריפו הזה כפי שהפרומפט מניח

**מה חסר.** ② מורה `worktree` לכל סוכן שנוגע בקוד, ו-⑥③ מורה "מיזוג · הרצת הרגרסיה". **אין
מנגנון לאף אחד מהשניים.**

**מהיכן ידעתי.** ‏`cat .gitignore` ⇒ **`node_modules`** ו-**`*.local`** מוחרגים. ⇒ ורקטרי טרי
נוצר **בלי `node_modules` ובלי `.env.local`**. ‏`grep -rho "E2E_[A-Z_]*" e2e/` ⇒ ה-E2E דורש
‏`E2E_CEO_EMAIL/PASSWORD` וארבעה זוגות נוספים, שכולם ב-`.env.local`.
*(לא יצרתי ורקטרי — זו כתיבה לריפו; הסקתי מ-`.gitignore` ומ-`git worktree list`.)*

**מה זה אומר בפועל:** בתוך ורקטרי **לא ירוצו** `npm run test:run`, `npm run gate`, `npm run dev`
ולא Playwright. ⇒ סוכן-כתיבה בורקטרי הוא **עיוור לחלוטין** — הוא יכול לערוך טקסט ולא יכול
לאמת דבר.

**מה להוסיף — במקום שורת ה-`worktree` ב-②:**
> • ‏`isolation:'worktree'` **רק לסוכני-כתיבת-טקסט**, ובידיעה ש**אין שם `node_modules` ואין
> ‏`.env.local`** (שניהם ב-`.gitignore`) ⇒ **סוכן בורקטרי אינו מריץ בדיקות — הוא מחזיר `diff` בלבד.**
> • **כל אימות (`test:run` · `gate` · `smoke` · E2E) רץ בעץ הראשי, על-ידך, אחרי המיזוג.**
> • **מנגנון-ההחזרה:** כל סוכן מחזיר **רשימת קבצים + הטקסט החדש**; אתה מחיל `Edit` בעץ הראשי.
> 🚫 אל תסמוך על "הסוכן קימט בורקטרי" — הגדר במפורש איך העבודה חוזרת.
