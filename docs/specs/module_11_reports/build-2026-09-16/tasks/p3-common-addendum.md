## 2. The `ReportSurface` extension slots (added 16/09 08:1X — THIS is how you add per-surface content; you never copy the shell)
`ReportSurface` renders the whole C8 payload generically: crumbs (drill surfaces) · population line · missing-params banner · `ExportBar` · tiles (`KpiTile`, doors via `tiles[].target` ⇒ `onDrill(target)`) · "אז מה" · charts (`ChartCard`) · `ReportTable` (sorted column ⇒ `aria-sort` from `meta.sort` or `columns[].sorted`) · **`meta.extra_tables` — rendered automatically, each with its title and pager (do NOT render them again)** · definitions + `meta.notes`. Your tab passes props:
- `transformPayload(payload) ⇒ payload'` — client-side chip filters (m16: the *"רק בלי דירוג"* default chip from `meta.default_filter`/`meta.no_rating_count` — the pager then counts what is shown, 📐8) · label mapping (`chart.label_source: 'WEEKDAY_NAMES_HE'` ⇒ replace `dow` 0–6 by the Hebrew weekday in the chart rows before render) · tile masking. **Returns the C8 shape; never deletes a key.** Runs only on a loaded payload (never on error).
- `renderTop(payload)` — above the population line: the surface's `purpose`/`whyAndFirst`/`why` `<Hint>`, your chip row, the m25 analysis-run bar (customers מ22).
- `renderBeforeChart(payload)` — rendered only when the payload has a chart: the "how to read the chart" hint.
- `renderBeforeTable(payload)` — rendered only when there are columns: the table hint.
- `renderExtras(payload)` — at the bottom: term hints (`reports.<slug>.term.*`), anything unique to the surface.
All four receive the payload **after** `transformPayload`. A per-surface component in `tabs/<tab>/<Surface>.jsx` that returns `<ReportSurface … transformPayload={…} renderTop={…} />` is the expected shape; the tab file switches on `surface.id`.
