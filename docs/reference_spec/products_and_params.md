# מבנה נתונים וטבלאות: מוצרים, דירוג מחירים ופרמטרים

## 🔒 החלטות Seed שננעלו (03/07/2026, ישי) — קובע לביצוע ה-Seed במודול 3

> הטבלאות למטה הן ה**מקור הגולמי** (מוקאפ). ה-Seed בפועל (במודול 3) יבוצע לפי ההחלטות הבאות, לא לפי הטקסט הגולמי מילה-במילה:

1. **Enum באנגלית** (העברית בטבלאות = תצוגה בלבד): `category` = `site`/`hostess`/`product` (אתר/דיילות/מוצרים); `status` → הכל `active`; `param_type` → 5 הערכים האנגליים (`pricing_timing`/`control_alerts`/`smart_match`/`templates`/`integration_tech`).
2. **SKU בלי מקף מוביל:** `06ST` (דיילת 6 שעות / אירוע ארוך), `04ST` (דיילת 4 שעות / אירוע קצר), `01WEB`.
3. **שירותים מתומחרים לפי `base_price`** (06ST=800, 04ST=500, 01WEB=2500 ללקוח); **אין שורות `price_tiers` לשירותים** — מדרגות מחיר רק לתגים/שרוכים. עמודת `cost` במוצרים = **העלות המלאה של החברה** על הדיילת (כולל כל ההוצאות), ולכן היא נראית גבוהה.
4. **פרמטרים:** מוסיפים `שכר_מינימום_שעתי = 35` (רצפה ל-`hostesses.hourly_rate`, משמש בדו"ח השכר החודשי לרו"ח). **לא מוסיפים** פרמטר "תעריף חיוב לדיילת" — חיוב הלקוח = מחיר המוצר לפי אורך המשמרת; שכר הדיילת = `hourly_rate` פר-דיילת.
5. **Smart-Match:** W3 = **מהימנות/PDR** (לפי אפיון 5.11, לא "עומס"); משקולות **W1=0.4 (דירוג) / W2=0.3 (מרחק) / W3=0.3 (מהימנות)**; פרמטר #9 יקרא `משקולת_3W_מהימנות`.
6. `max_qty` במדרגה העליונה = **NULL** (=אינסוף), לא 99999.
7. לטבלת `params` אין עמודת תיאור — התיאורים הפונקציונליים הם תיעוד בלבד.
8. תיקוני טעויות: `שרוך כותנה עם לוגו`; `מייל_משרד_רואי_חשבון`.
9. `image_url` = placeholders בשלב זה.
