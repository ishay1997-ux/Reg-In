# נוהל ומדדי בדיקת בריאות המערכת (QA & Health Pulse)

> **תפקיד המסמך:** הגדרת מדדי התקינות של המערכת ורוטינות הבדיקה השוטפות.

---

## 1. בדיקות עשן מקומיות (`npm run smoke`)
- **פקודה:** `npm run smoke` (מריצה את `node scripts/smoke.mjs`).
- **סביבה:** שרת פיתוח חי (`http://localhost:5173`).
- **זמן ריצה ממוצע:** ~13 שניות.
- **מה נבדק:** מסע קריאה בלבד בכל מסכי המערכת המרכזיים מול ערכי עוגן ידועים (`e2e/smoke-anchors.json`).
- **קודי יציאה:**
  - `0`: הצלחה מלאה.
  - `1`: באג פונקציונלי / אי-התאמת תוכן.
  - `2`: שגיאת אימות / משתמש לא מורשה.
  - `3`: שרת הפיתוח אינו פעיל.

---

## 2. סוויטת בדיקות E2E (`npm run test:e2e`)
- **פקודה:** `npm run test:e2e`.
- **סביבה:** שרת Preview מקומי (`http://localhost:4173`, מוגדר ב-`playwright.e2e.config.js`).
- **היקף:** 19 קובצי בדיקות, 117+ בדיקות פונקציונליות ונגישות (`accessibility.spec.js`).
- **עיקרון יירוט רשת:** כל הבדיקות רצות באמצעות `page.route` (יירוט תשובות רשת) ללא הזרקת שורות בדיקה למסד החי.

---

## 3. סוויטת בדיקות יחידה (`npm run test:run`)
- **פקודה:** `npm run test:run` (Vitest).
- **היקף נוכחי:** 98 קובצי בדיקה, **2,402 בדיקות**, 100% ירוק.
- **אילוץ מכונה:** `maxWorkers: 3` ב-`vite.config.js` למניעת חנק זיכרון במכונות פיתוח עם 16GB RAM.
