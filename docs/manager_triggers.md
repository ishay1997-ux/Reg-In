> חוזה** — מה בדיוק קורה כשאתה אומר מילה מסוימת. נוצר 01/08/2026 (מנהל-3) לבקשתך.
>
> 🔴 **המילה היא הטריגר, לא הכוונה.** אם תאמר ניסוח דומה שאינו כאן — **המנהל ישאל ולא ינחש.**
> *(זה קרה היום: "בוא נסיים" אינו ברשימה, ונשאלת מה התכוונת.)*

## 🎯 מילות-הכרעה — סוגרות פריט

| מה שתאמר | מה זה עושה |
|---|---|
| **"בצע לפי המלצתך"** | **הכרעה, לא האצלה-לחשוב-שוב.** הסעיף **סגור** ולא נשאל שוב · ואתה מקבל **סיכום כפול**: מה המשתמש יראה + מה קרה מאחורי הקלעים |
| **"לא קורה"** | **סוגר את הפריט וגם מזיז עדיפויות.** ‏🔴 ומרגע זה **אסור לבנות לוגיקה למקרה הזה** — לעולם |
| **"מספיק להיום"** | עוצר באמצע רשימה, **ורושם בדיוק איפה נעצרנו** כדי שנמשיך משם. **לגיטימי לחלוטין** |
| **"לא הבנתי"** | **דוח-תקלה על ההסבר שלי, לא עליך.** אני פותח מחדש **בתוצאה מעשית** ("תלחץ X, יקרה Y") ולא מסביר את המושג שוב |
| **"יד חופשית ב-X"** | שיקול-דעת מלא **ב-X בלבד** — ואני מדווח לך **גם מה דחיתי**, לא רק מה עשיתי |
| **"בוא נבצע"** | שיקול-דעת מלא **בתוך מבחן-הסמכות.** ‏🚫 **אינו מרשה:** כוונת-מוצר · משהו שהמשתמש רואה · שום דבר בלתי-הפיך — **אלה ממשיכים לעלות אליך** |

## 🔍 שאלות-החפירה שלך — הן עובדות גם עליי

| מה שתאמר | מה זה מוציא |
|---|---|
| **"מה עוד לא בדקת?"** | פערי-**אימות** שדיווח חיובי מסתיר |
| **"על מה עוד לא חשבת?"** | **שיקול** חסר — משלים את הקודמת |
| **"יש משהו נוסף או שסיימת?"** | עבודה או ספק שהוחזקו בשקט |
| **"אתה בטוח? אולי X?"** | ספק **עם כיוון** — יעיל בהרבה מ"בדוק שוב" עירום |
| **"קראת?"** | מכריח אותי להודות אם פעלתי על קובץ שלא פתחתי |
| **"מה מקובל בעולם?"** | בדיקת-שוק לפני החלטת-**גישה** (לא לזוטות מכניות) |
| **"תעבור תבדוק אם זה הסדר הנכון"** | סידור מחדש לפי **נזק שמחמיר עם נתוני-אמת** |

## 🔧 מילות-עבודה — מפעילות סקיל

| מה שתאמר | לאן זה הולך |
|---|---|
| **"אתה מנהל העבודה"** / *"מנהל הפרויקט איתי"* | טוען את סקיל-המנהל · עולה מהדיסק · **מדווח מיקום ומחכה** |
| **"פתח מודול N"** | ‏`module-blueprint` + **סריקת רשם-החובות** של אותו מודול |
| **"סגור את המודול"** | ‏`module-close` — **בסשן טרי**, כי מי שבנה נוטה לאשר את עצמו |
| **"מיזגתי"** / **"עשיתי merge"** | ‏`post-merge` — **ראיית-גיט טרייה בלבד** · היפוך שורות-מצב · **והודעה לכל סשן חי שהענף מת** |
| **"בוא נסגור שאלות פתוחות"** | ‏`section7-rulings` — **בסשן ייעודי**, לא אצל המנהל |
| **"עשה סקירת קוד"** | ‏`quality-audit` — יקר, סורק את כל הקוד |
| **"תראה לי מה בנית"** | ‏`feature-acceptance` — סיור בנוי-מול-כוונה. **מוצע וממתין לאישורך** |
| **"בוא נתייעץ עם המועצה"** | ‏`llm-council`. **המנהל רשאי גם ליזום** בהחלטה כבדה שהוא קרוע בה |

## ⛔ מה ש**אינו** טריגר

**"בוא נסיים" · "תמשיך" · "קדימה" · "בסדר"** — **אלה ממשיכים את מה שרץ, לא מתחילים תהליך.**
אם המשמעות אמורה להיות אחת מהטבלאות שלמעלה — **אשאל, לא אנחש.** *(וזה מכוון: ניחוש-טריגר מפעיל
תהליך שלם שלא ביקשת.)*
