## ④ החלק שלכם

1. שבו יחד (או בשיחת וידאו) והכריעו ב-§7.17 ו-§7.7.
2. `git checkout -b shared/module-6-projects` (ענף משותף — תאמו commits בין השניים).
3. הדבק פרומפט, אשרו בלופרינט, בנו יחד — מחלקים את הצעדים בין UI (עמית) ל-לוגיקה/DB (ישי) לפי מה שהבלופרינט יציע.
