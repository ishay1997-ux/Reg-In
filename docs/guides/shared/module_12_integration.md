# 🚀 שלב — מודול 12: אינטגרציה והגשה 🤝 משותף

> מקומו בהיררכיית האמת: `schema.sql` › אפיון › מוקאפים › מדריך זה. בסתירה — המדריך מפסיד.
> צעדים שבוצעו מסומנים ✅ — המדריך כתוב כאילו כלום לא קיים.
> **מודול משותף — וגם היחיד שבו המערכת עולה לאוויר (Vercel).** לפי ההחלטה של ישי, הפריסה **לא** קורית קודם — לא במודול 0, לא באמצע. רק כאן, כשהכל מוכן.

## ① מה נשיג בשלב הזה

כיסוי E2E מלא לכל 12 המודולים (לא רק מודול 1), Seed data מלא לדמו/הגשה, ליטוש UI/UX סופי, **פריסה חיה ל-Vercel**, ו-UAT (בדיקת קבלה סופית עם משתמשים אמיתיים או תסריט מלא). זה אבן דרך M5 מ-[00_roadmap.md](../00_roadmap.md).

## ② תנאי כניסה

- [ ] כל המודולים 1–11 מוזגו ל-`dev`.
- [ ] `dev` עצמו יציב (`npm run verify` ירוק, כל ה-E2E הקיים עובר).

| מחליט על משתני סביבה ב-Vercel; מחבר את הריפו ל-Vercel | כותב/מרחיב E2E specs למודולים שלו | מרחיב E2E, בונה Seed, מלווה את חיבור Vercel |

## ④ החלק שלכם

1. **הרחבת E2E:** לכל מודול (2–11) — ודאו שיש `e2e/module-N.spec.js` שמכסה את תרחישי ⑦ מכל מדריך שלב. `regin-e2e-check` (ר' [docs/claude_routines.md](../../claude_routines.md)) כבר כתובה גנרית ותרוץ על כל הקבצים שקיימים — אין צורך לעדכן אותה, רק להוסיף specs.
2. **Seed data להגשה:** נתונים ריאליסטיים (לא רק "לקוח 1", "לקוח 2") לכל הטבלאות — כדי שדמו/הגשה יראו טוב.
3. **חיבור Vercel** (**כאן ולא קודם**):
   - היכנס ל-**vercel.com** → **Add New Project** → ייבוא הריפו מ-GitHub.
   - הגדר משתני סביבה (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) בהגדרות הפרויקט ב-Vercel (Settings → Environment Variables) — **לא** בקוד.
   - Deploy. `vercel.json` הקיים כבר מגדיר SPA rewrite לראוטר.
4. **UAT:** תנו למישהו שלא בנה את המערכת (או תסריט "עיוור") לעבור על תסריטי השימוש המרכזיים ולדווח בעיות.

## ⑤ החלק של Claude

מרחיב E2E לפי המודולים שנבנו, בונה סקריפט Seed, מלווה את חיבור Vercel (בדיקת build תקין, `vercel.json`, משתני סביבה), מריץ audit סופי (lint+test+build+E2E מלא), ומעדכן את `docs/claude_routines.md` אם `regin-e2e-check` צריכה עדכון בפועל (ר' טבלת "טריגרי צמיחה" שם). **מציית לשפת העיצוב ולטבלת הצבעים ב-PROJECT_MASTER §4** — זה שלב ליטוש, לא שלב שינוי-עיצוב.
