# 📚 ספריית הפרומפטים המצביים — REG-IN

> מקומו בהיררכיית האמת: הוראות תפעוליות בלבד.
> **מה יש כאן:** פרומפטים מוכנים להדבקה לסיטואציות שחוזרות על עצמן — תקלות, שינויים, שאלות. **מה אין כאן:** פרומפטי הפתיחה/המשך/סגירה של מודול — הם חיים בסעיף ⑥ של מדריך השלב שלך (כבר ממולאים פר-מודול). מתי מריצים רוטינות — [המפה ב-claude_routines.md](../claude_routines.md).

## <a name="p5"></a>P5 · ‏merge conflict
🕐 כש-git עוצר עם conflict (במשיכה, במיזוג, ב-PR).
```
אני ישי. יש לי merge conflict ב-git ואני לא בטוח מה לעשות.
הפקודה שהרצתי: ___
מה git הציג (הדבק במלואו): ___
תסביר לי בעברית פשוטה: מה מתנגש עם מה, ומה כל צד של הקונפליקט אומר.
הצע פתרון והסבר למה דווקא הוא — אל תבצע לפני שאישרתי.
(רמז נפוץ בפרויקט: קונפליקט בשורת "_(שורה חדשה כאן)_" של CHANGELOG/יומנים = שני ענפים הוסיפו
רשומות באותה נקודה — הפתרון כמעט תמיד keep-both, ממוין לפי תאריך+שעה.)
אסור בשום מצב: git push --force, או מחיקת עבודה שכבר נדחפה.
אחרי הפתרון: הרץ npm run verify והראה לי שהכל ירוק.
```
