# החלף את השם בקובץ-התמליל של הסשן הרלוונטי (התיקייה: ~/.claude/projects/<repo>/)
python -c "
import json
p='<SESSION_ID>.jsonl'; msgs=[]
for line in open(p,encoding='utf-8'):
    try: d=json.loads(line)
    except: continue
    if d.get('type')!='user': continue
    c=d.get('message',{}).get('content')
    t=c if isinstance(c,str) else ' '.join(x.get('text','') for x in c if isinstance(x,dict) and x.get('type')=='text') if isinstance(c,list) else ''
    t=t.strip()
    if not t or t.startswith('<') or 'Caveat:' in t[:80] or 'system-reminder' in t[:80]: continue
    msgs.append(t)
out=open('ishay_msgs.txt','w',encoding='utf-8'); out.write('TOTAL: %d\n\n'%len(msgs))

out.close(); print('OK',len(msgs))
"
