# 🔧 שלב 01 — התקנות במחשב שלך (עמית)

> מקומו בהיררכיית האמת: הוראות טכניות בלבד — אין כאן הכרעות עסקיות.
> **זה השלב היחיד בלי Claude** — עדיין לא מותקן. בכל שלב אחרי זה, Claude יעשה בשבילך את רוב העבודה.

## ① מה נשיג בשלב הזה

המחשב שלך מוכן לפתח: **VS Code** (העורך), **Git** (ניהול גרסאות), **Node.js גרסה 20 ומעלה** (מריץ את הקוד), ו**Claude Code** (הכלי שיעשה בשבילך את רוב העבודה מכאן והלאה). ⏱️ ~45 דקות.

## ② תנאי כניסה

- מחשב Windows + חשבון Google (לכניסה ל-Claude/GitHub בהמשך).

## ③ חלוקת עבודה

| אתה | ישי | Claude |
|---|---|---|
| מתקין הכל בעצמך (4 התקנות, אשפים גרפיים) | זמין בוואטסאפ אם משהו תקוע | — (עדיין לא מותקן בשלב הזה) |

## ④ החלק שלך

### א. VS Code
1. גלוש אל **https://code.visualstudio.com**.
2. לחץ **Download for Windows**.
3. פתח את הקובץ שירד, עבור את האשף עם ברירות המחדל (Next → Next → Install → Finish).

### ב. Git for Windows
1. גלוש אל **https://git-scm.com/download/win**.
2. לחץ **"Click here to download"**.
3. פתח את הקובץ, השאר ברירות מחדל בכל המסכים (יש הרבה מסכים — זה תקין, לא לשנות כלום), **Install → Finish**.

### ג. Node.js LTS
1. גלוש אל **https://nodejs.org**.
2. לחץ על הכפתור הירוק עם הכיתוב **LTS** (למשל "22.x.x LTS"). **אל תבחר "Current"** — הפרויקט דורש גרסה 20 ומעלה, ו-LTS תמיד עומד בזה.
3. פתח את הקובץ, אשף בברירות מחדל, **Install → Finish**.

### ד. Claude Code
1. גלוש אל **https://claude.com/claude-code** (או פתח את מה שישי הראה לך).
2. עקוב אחרי הוראות ההתקנה במסך (בדרך כלל: פתיחת טרמינל והדבקת פקודת התקנה קצרה).
3. התחבר עם חשבון Claude שלך (אם אין לך — צור אחד באתר claude.ai).

### ה. הפעל מחדש
סגור את כל החלונות הפתוחים (טרמינל, VS Code) ופתח מחדש — כדי שהמחשב "יראה" את הכלים החדשים ב-PATH.

## ⑦ בדיקת קבלה

פתח טרמינל חדש (או PowerShell) והרץ כל אחת מהפקודות הבאות — כל אחת צריכה להחזיר מספר גרסה, לא הודעת שגיאה:
```
node -v
git --version
claude --version
```
ו-VS Code נפתח בלחיצה על האייקון שלו.

## ⑧ אם משהו השתבש

- **"‎'node' is not recognized"** (או `git`/`claude`) — לא הפעלת מחדש את הטרמינל אחרי ההתקנה. סגור את כל חלוני הטרמינל/PowerShell ופתח מחדש.
- **ההורדה נחסמה ע"י אנטי-וירוס** — הורד רק מהכתובות הרשמיות שלמעלה, ואשר את ההרצה אם Windows שואל.
- **התקנה נתקעת** — נסה להריץ את קובץ ההתקנה **כמנהל** (קליק ימני → "Run as administrator").
- כל דבר אחר — שלח הודעה לישי עם צילום מסך של השגיאה.
