# 🚀 שלב 03 — הרצה ראשונה + סיור מודרך

> מקומו בהיררכיית האמת: הוראות תפעוליות בלבד.
> צעדים שבוצעו מסומנים ✅.

## ① מה נשיג בשלב הזה

הפרויקט רץ על המחשב שלך (`localhost:5173`), אתה מצליח להתחבר עם משתמש בדיקה, ו-Claude נותן לך סיור מודרך בקבצים החשובים — כדי שתבין את המבנה לפני שאתה מתחיל לבנות.

## ② תנאי כניסה

- [ ] [02_accounts_and_access.md](02_accounts_and_access.md) הושלם.

## ③ חלוקת עבודה

| אתה | ישי | Claude |
|---|---|---|
| מריץ פקודות, מדביק את הפרומפט | שולח לך פרטי משתמש בדיקה (בערוץ פרטי) | סיור מודרך, מוודא ש-verify ירוק |

## ④ החלק שלך

1. בתיקיית הריפו:
   ```
   npm install
   npm run verify
   npm run dev
   ```
2. פתח דפדפן ב-`http://localhost:5173`.
3. בקש מישי כתובת+סיסמה של משתמש בדיקה מתאים לתפקיד שלך (מנהלת פרויקטים/כספים/גיוס/לוגיסטיקה — לא המנכ"ל, זה החשבון של ישי) — **בערוץ פרטי, לא בצ'אט עם Claude ולא בריפו**.
4. התחבר עם הפרטים.

## ⑤ החלק של Claude

עורך סיור מודרך: מסביר בקצרה מה כל תיקייה עושה (`src/modules/`, `src/components/`, `src/contexts/`, `supabase/migrations/`), מציג את סדר הקריאה המומלץ (`CLAUDE.md` → `STATUS.md` → `docs/guides/00_roadmap.md` → `docs/PROJECT_MASTER.md` §1-3 → `docs/micro_guides/module-1.md` כדוגמה לאיך מודול נבנה בפועל), ומוודא ש-`npm run verify` ירוק אצלך.

## ⑥ 📋 הפרומפט להדבקה

```
היי Claude. אני עמית, המפתח השני בפרויקט REG-IN. זו הפעם הראשונה שלי בריפו.
קרא CLAUDE.md, STATUS.md ואת docs/guides/amit/03_first_run.md,
ואז קח אותי לסיור: הסבר לי מה כל תיקייה עושה, ודא ש-npm run verify ירוק אצלי,
והצג לי את סדר הקריאה המומלץ. אל תשנה שום קובץ.
```

## ⑦ בדיקת קבלה

- [ ] `npm run verify` מסתיים בהצלחה (בלי שגיאות אדומות).
- [ ] האתר נפתח ב-`localhost:5173`.
- [ ] כניסה עם משתמש הבדיקה שלך מצליחה, ואתה רואה תפריט צד עם המודולים המתאימים לתפקיד שלך.

## ⑧ אם משהו השתבש

- **`npm install` תקוע/נכשל לזמן ארוך** — תקלה מוכרת מוגדרת ב-04/07: הרץ `set NODE_OPTIONS=--use-system-ca` (PowerShell: `$env:NODE_OPTIONS="--use-system-ca"`) ואז נסה שוב.
- **שגיאת חיבור ל-Supabase בדפדפן** — השווה את `.env.local` שלך מול `.env.example` — ייתכן ששם משתנה לא תואם.
- **כניסה נכשלת** — ודא עם ישי שהחשבון שלך `status='active'` ולא ננעל (5 ניסיונות כושלים = נעילה ל-15 דקות).
