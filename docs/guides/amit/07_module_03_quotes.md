## ① מה נשיג בשלב הזה

מנוע התמחור: המלצת מספר דיילות (`אורחים/50`), תמחור שירותים + מחירון מדורג לתגים/שרוכים, הנחות (לקוח קבועה + ידנית), חישוב מע"מ, PDF, וסטטוס הצעה (`בתהליך → מאושרת/נדחתה`). מסך 5.4-5.5 באפיון. **מודול הכסף** — יש כאן דוגמת בדיקה מדויקת מהאפיון.
