## ① מה נשיג בשלב הזה

סגירה פיננסית של פרויקט: שליחת חשבונית, קבלת משוב לקוח (1-5 כוכבים + טיפול בציון נמוך), תאריך תשלום, וחישוב **רווח גולמי** (הכנסה נטו לפני מע"מ לאחר הנחות, מינוס עלות עבודה ועלות חומרה בפועל). מסך 5.13-5.14 באפיון.
> 🔗 **מראת §7.38+16** (שתי ההערות הבאות) — SSOT: ‏PROJECT_MASTER §7 (לא לערוך כאן ידנית; מסונכרן ע"י `regin-docs-sync`)
> ℹ️ **§7.38 הוכרע (07/07/2026, ישי):** המערכת **אינה מפיקה** חשבונית. הכספים **מעלה קובץ-חשבונית** → "שמור ושלח" → הודעה קופצת → המערכת שומרת+שולחת במייל+מסמנת ✓ `invoice_sent`. דפוס מימוש = כמו העלאת חומר שיווקי במודול 2 (Storage + שליחה).
> ℹ️ **§7.16(ב) הוכרע (07/07/2026, ישי) — חישוב שכר בביטול פרויקט (אוטומטי כאן):** לפי `projects.cancelled_at` + `cancellation_reason` enum(`standard`,`force_majeure`): **>72ש'** → 0% · **24–72ש'** (`standard`) → **50%** משעות-המשמרת המתוכננות · **<24ש'** → **100%** · **`force_majeure`** → 0%, ללא תלות בזמן. וכן **§7.16(א):** דיילת שלא הגיעה (מכל סיבה) = **בלי תשלום ובלי הוספת שעות**. השדות נוספים בסכמת מודול 4 (§7.47).
