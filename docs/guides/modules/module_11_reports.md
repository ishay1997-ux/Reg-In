## ⑥ 📋 שלושת הפרומפטים להדבקה

> 💡 **בחירת מודל לפני הדבקה:** פרומפט 1 (פתיחה) ופרומפט 3 (סגירה) — **Opus, מאמץ גבוה** (חשיבה: בלופרינט, RLS, אודיט). פרומפט 2 (המשך-בנייה) — לפי טבלת **Model & effort** שבראש סעיף 5 של מדריך המיקרו (ברירת מחדל: Sonnet לפזות בנייה, Opus לפזות DB/RLS ובקרה).

**1) פתיחת מודול (פעם אחת):**
```
אנחנו בפרויקט REG-IN. קרא את CLAUDE.md, STATUS.md, docs/guides/modules/module_11_reports.md
ואת docs/PROJECT_MASTER.md (סעיף 5.17).
אנחנו פותחים את מודול 11 — דו"חות מנהלים, על ענף ishay/module-11-reports.

קרא בעצמך את התבנית docs/templates/create_micro_guide_template.md ובצע אותה כלשונה עם:
MODULE_NUMBER=11 · MODULE_NAME=דו"חות מנהלים · RELEVANT_SECTIONS=§5.17 · BRANCH_NAME=ishay/module-11-reports

חובה: "שאלות פתוחות" מסעיף ② במדריך שלי = פריטי §7 — הצג לי אותן להכרעה (§7 = ישי, כלל 1), אל תכריע בהן לבד.
הצג את הבלופרינט לאישורי; רק אחרי שאאשר — שמור אותו כ-docs/micro_guides/module-11.md.
```

**2) המשך בנייה (בכל סשן עבודה, עד שכל הצעדים ✅):**
```

המשך מ"הצעד הפעיל" שבכותרת המצב. אמת בעצמך כל נקודת עצירה 🤖 (הרץ את פקודת האימות והצג ראיה),
ועצור לאישורי בכל נקודת 👤 ובסוף כל פזה.
נכנסת לפזה חדשה? אסוף קודם את כל השאלות הפתוחות/ממתינות-להנהון המעוגנות אליה בלדג'ר (סעיף 3)
והצג לי אותן לסגירה במרוכז (סגנון P13) לפני הצעד הראשון של הפזה. עדכן את מדריך המיקרו תוך כדי העבודה (סעיף 8 שלו).
בסוף הסשן: עדכן יומנים לפי הפרוטוקול ב-CLAUDE.md והסבר לי בעברית פשוטה איפה עצרנו ומה הבא.
```
