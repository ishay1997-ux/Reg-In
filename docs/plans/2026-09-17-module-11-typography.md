## 2 · שכבה 1 — סקאלת טיפוגרפיה *(הבסיס; בלעדיה השאר נסחף שוב)*

**קובץ:** `src/index.css`, בתוך `@theme inline` הקיים (שם כבר יושבים `--color-*` ו־`--radius-*`).
ב־Tailwind v4 הגדרת `--text-*` **דורסת את הסקאלה המובנית גלובלית** — אין `tailwind.config.js` בריפו
במכוון (`src/CLAUDE.md §2.3`).

```css
--text-xs:   0.8125rem;  /* 13px — רצפה מוחלטת: צירי־גרף ומקרא בלבד */
--text-sm:   0.875rem;   /* 14px — כל טקסט־משנה והסבר */
--text-base: 1rem;       /* 16px — גוף */
--text-2xl:  1.5rem;     /* 24px — ערך של כרטיס־מדד */
```
