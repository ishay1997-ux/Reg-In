בנוסף, סכמה שאינה `public` **אינה חשופה דרך ה-API** — העותקים בלתי-נגישים מהדפדפן.

## 3. 🔴 הגבול של מה שנעשה — ואסור לטעות בו

**זהו גיבוי בתוך אותו מסד.** הוא מציל אותך מ-`UPDATE` שגוי, מסקריפט-זריעה שדרס נתון,
ומטעות אנוש. ‏**הוא אינו מציל אותך מאובדן הפרויקט עצמו** — אם פרויקט Supabase נמחק,
מושהה או מאופס, **הגיבוי נמחק איתו.**

## 4. ✋ מה שנשאר לך — עותק אחד מחוץ למסד

הפקודה למטה מייצרת קובץ `.sql` על המחשב שלך, מחוץ ל-Supabase. **היא דורשת את סיסמת-המסד,
ולכן היא שלך להריץ ולא של קלוד** — קלוד אינו מזין סיסמאות, וזה לא כלל של הפרויקט אלא כלל
שחל תמיד.
